01 // Foundation

Design Principles

The core philosophy that governs every UI decision in Subnautica. These principles create tension between beauty and function.

01
Diegetic UI

The interface should feel like it belongs to the world. HUD elements read as projections on a diving mask or a PDA screen, not arbitrary overlays. Every element reinforces the fiction of survival technology.

02
Survival Clarity

Information hierarchy is life-or-death. Oxygen is the most visible element. Colors encode meaning: cyan for system-normal, amber for warning, red for critical. No ambiguity at depth.

03
Holographic Materiality

UI surfaces are translucent, glass-like, with subtle scan lines and chromatic edges. They float rather than sit heavy on screen. Glow replaces solid fills. Light bleeds at borders.

04
Biome as Canvas

The underwater world is never obscured. UI panels are semi-transparent and desaturated so the environment remains the star. The interface adapts to light levels, never fighting the scene.

05
Precursor Mystery

Alien technology introduces a second visual language: hard-edged geometry, etched glyphs, and an unsettling green glow. It contrasts with the organic softness of ocean life and the utilitarian human tech.

06
Restrained Motion

Animation is purposeful, never decorative. Bars deplete smoothly. Notifications slide in with weight. Critical states pulse slowly. Fast or jittery movement breaks the meditative underwater pacing.

05 // Materials

Surface & Effects

The physical qualities of UI surfaces. Glass, glow, and holographic instability create the feeling of a heads-up display projected onto a visor.

Glass Panel
Glassmorphism

Dark translucent base with backdrop blur. Thin cyan border at low opacity. Contents remain readable while the world bleeds through.

Ambient Glow

Soft radial gradients behind key elements. Not a hard drop shadow — a diffuse bloom that suggests underwater light scattering.

HOLOGRAM
Holographic Flicker

Occasional opacity dips simulate an imperfect projection system. Timing is irregular — 4-6 second intervals with brief micro-flickers.

Scan Lines

Horizontal lines at 3px intervals with extremely low opacity (0.015). Creates texture without noise. Applied globally as a fixed overlay.

07 // Motion

Animation Language

Timing and easing definitions for the interface. Underwater pacing means slow, fluid motion. Nothing snaps unless it is a warning.

Standard Ease
0.4s // power2.out

Default for hover states, panel transitions, and tab switches.

Ambient Drift
3s // sine.inOut

Background elements, god rays, and particle motion. Imperceptibly slow.

Panel Entrance
0.5s // power3.out

Menus and notifications slide in with weight, then settle softly.

Critical Pulse
1.5s // sine.inOut // repeat

Low oxygen, health warnings. Slow, insistent rhythm. Never frantic.

Emergency Snap
0.15s // power1.out

Rare. Used only for damage indicators and sudden system failures.

Hologram Flicker
Random // 4-6s intervals

Irregular opacity dips to simulate an imperfect projection system.
