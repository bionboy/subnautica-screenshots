# Subnautica Screenshots Collection

A curated collection of screenshots from the *Subnautica* franchise, gathered for art-style analysis and reference.

## Games

- **Subnautica** (original) — 10 screenshots from various biomes including Kelp Forest, Safe Shallows, Crash Zone, and night scenes.
- **Subnautica: Below Zero** — 5 screenshots from arctic biomes, including the Frozen Leviathan site, Glow Whale encounters, and icy seabases.

## Source

Screenshots gathered from the Steam Community screenshot galleries for both games, filtered to include only actual in-game screenshots.
